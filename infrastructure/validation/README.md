# Workspace MVP Validation

Validate the workspace with real alpha and beta activity. Use admin analytics and
read-only database queries to record activation, chat completion, repeat use,
provider reliability, quota behavior, billing conversion, and safety defects.

Report the numerator, denominator, UTC window, account filter, and query version
with every percentage. Suppress small cohorts in public reports.

Ship only when at least five alpha testers complete the core tasks, no S1/S2
privacy or authorization issue remains, the backup restore rehearsal succeeds,
and provider costs and usage records reconcile for the validation window.
